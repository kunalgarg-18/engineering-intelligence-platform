# Architecture Journal

## Purpose

This journal captures architectural exploration rather than finalized decisions. It provides a focused place to record and examine one architectural question at a time while the topic is still being explored.

## Relationship with Other Documentation

- **ADRs:** ADRs record significant, durable architectural decisions after review. Journal entries support exploration and do not establish decisions.
- **Ubiquitous Language:** Use the Ubiquitous Language to keep exploration consistent with shared domain terminology.
- **Domain Model:** Journal entries may relate to questions that inform the Domain Model, but they do not define it.
- **AI Context:** AI Context provides execution guidance for AI-assisted work; journal entries provide exploratory architectural context.

## Guidelines

Every future architectural question should become a new journal entry. Each entry should focus on one question and remain exploratory until any resulting decision is reviewed and recorded in the appropriate document.

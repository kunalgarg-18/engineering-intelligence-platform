# Architecture Decision Records

Architecture Decision Records (ADRs) document significant, durable technical decisions after review.

## Status Values

- `Proposed` — under review; not an implementation directive.
- `Accepted` — approved and applicable.
- `Superseded` — replaced by a newer ADR.
- `Deprecated` — no longer applicable.

## Record Template

```md
# ADR-XXXX: [Decision Title]

## Status

`Proposed`

## Context

<!-- What decision is needed and why? -->

## Decision

<!-- What has been decided? -->

## Consequences

<!-- What follows from this decision? -->

## Alternatives Considered

<!-- Which viable alternatives were evaluated? -->

## References

<!-- Link relevant requirements, designs, or prior ADRs. -->
```

## Naming

Use a zero-padded sequential filename: `NNNN-short-decision-title.md`.

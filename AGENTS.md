# Guidance for AI Assistants

## Required Reading

Before generating, changing, or proposing code, read the relevant documentation in `docs/` and all applicable Architecture Decision Records in `docs/adrs/`.

## Working Agreement

- Treat documentation and accepted ADRs as the source of truth.
- Do not infer or introduce architecture, domain models, APIs, data models, or product behavior that has not been documented and approved.
- If required direction is missing, identify the gap and request a design decision rather than inventing one.
- Keep implementation changes aligned with approved documentation and ADRs.
